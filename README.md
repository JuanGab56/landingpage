# Landing Page - Academia de Programación

Proyecto web organizado en HTML, CSS y JavaScript.

## Estructura

academia-programacion/
├── index.html
├── css/
│   └── styles.css
└── js/
    └── script.js

## Cómo ejecutar

1. Abra la carpeta `academia-programacion` en Visual Studio Code.
2. Abra `index.html` en el navegador.
3. Opcionalmente use la extensión Live Server.

## Funcionalidades

- Diseño responsive.
- Menú adaptable a móviles.
- Sección principal o Hero.
- Tarjetas de cursos.
- Sección de beneficios.
- Formulario de contacto con validación básica en JavaScript.
- Año del footer generado automáticamente.
